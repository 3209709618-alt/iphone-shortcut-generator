# 静态版状态与验证记录

日期：2026-10-15。用户改为先做静态网站，原来的在线后台方案保留。

## 交付边界

React / TypeScript / Vite 静态应用，打包输出 `dist/`。不含在线后台、登录、云数据库、运行时 AI 代理或虚假的安装入口。自然语言理解由用户设置的真实模型接口提供，不做关键词模板冒充 AI。

当前流程：需求文字和截图 → 可选追问 → 校验结构化计划 → 步骤预览 → 浏览器确定性编译 → 未签名 plist。最后的合法签名与真实 iPhone 导入未通过，**用户要求的完整核心目标仍未完成**。

首批八种动作：文本、询问输入、读取剪贴板、复制已有文字、显示结果、朗读文本、即时通知、打开明确的 HTTPS 网页。支持文字变量、外部快捷指令输入和自由组合。其余动作返回限制和替代建议，不能悄悄丢弃核心需求。没有开放文件写入、提醒事项、条件、循环或运行时 AI，原快递/记账案例仍待完成。

浏览器不能启动 Cherri 的 Go 命令行进程，因此采用独立 TypeScript plist 序列化器；动作标识、参数和变量编码使用 Cherri v2.3.0 的实际输出作对照。编译不是签名，文件扩展名刻意使用 `.unsigned.plist`。

## 当前网络证据

- 对 `https://api.deepseek.com/chat/completions` 发出带 Origin 的 OPTIONS 预检，返回 HTTP 200，并允许该 Origin、POST、authorization 和 content-type。表明浏览器直连的预检可行，不能代替持有密钥的真实调用及用户大陆网络测试。
- 对 `https://hubsign.routinehub.services/sign` 的 HEAD 返回 HTTP 403、HTML、Cloudflare 响应。未绕过限制，未 POST，未上传任何文件。没有证明服务永久不可用，也未确认权限、免费额度、跨域支持或签名真实性。
- [Cherri 签名说明](https://cherrilang.org/compiler/signing.html) 区分 macOS 的 `shortcuts sign` 与远程签名服务；纯静态网页自身没有 Apple 签名能力。

可行后续：确认一个合法、允许浏览器跨域调用且符合预算的签名服务；用无个人信息的最小文件签名，再由真实 iPhone 导入运行。若服务要求代理，需要重新决定是否允许小型后台。不会自动购买付费方案、开通超额计费或要求用户购买 Mac。

## 数据与模型设置

- API 密钥只在页面内存，保存后仅显示掩码与状态，刷新即失效；不写入 IndexedDB、localStorage 或文件。更换接口地址须重填密钥，避免误发给其他服务商。
- 所选接口必须为公共 HTTPS 域名，禁止字面 IP、本机/内网后缀、URL 用户名、查询串与非标准端口。静态网页不能解析和固定远端 DNS，因此这不是后台级 DNS/SSRF 防护承诺。不要配置不信任的模型服务。
- 请求不带站点 Cookie，拒绝重定向，90 秒超时。HTTP/网络错误不自动重试，不回显供应商响应中的潜在秘密。只在结构校验失败时自动修正一次，按钮附近说明可能计费。
- 对话、附件、每次成功方案和编译文件存于本浏览器 IndexedDB。事务中比较记录修订号，过期页面不能覆盖新记录。失败时保留旧版本；刷新后显示中断记录，不重复发起调用。关闭页面时的模型请求可能仍在供应商侧计费；静态版没有可在页面关闭后继续运行的后台任务。
- 截图支持 PNG/JPEG/WebP，≤5 MB、≤3 张、≤2400 万像素，校验文件头并实际解码。读取完成才可发送；不支持图片的模型禁止图片请求（包含历史图片的对话也不静默忽略）。
- 浏览器没有服务器端访问密码；同设备同浏览器其他使用者可查看记录。不保证云同步。可导出 JSON 对话备份，当前不提供自动恢复导入；清理前保留原始备份文件。

- `npm test`：10 项 TypeScript 测试与原有 7 项 Python 测试通过，覆盖动作/参数/引用验证、HTTPS 地址、XML 转义和 UTF-16 变量偏移、确定性输出、模型设置生效、最多一次修正、不支持图片拒绝、错误脱敏及取消。
- `npm run verify:compiler`：原有 4 个探针保持通过；新第 5 个探针包含全部 8 种动作。将两端 UUID 一致重命名后，浏览器输出完整 Apple plist 与 Cherri 输出相同。每个探针编译两次并比对字节。报告 `.local/checks/compiler-cziu6hev/report.json`。
- `npm run build`：TypeScript 与静态打包通过。Vite 使用已修复安全问题的 7.3.7，安装时 npm 审计无已知漏洞。
- `npm run test:ui`：隔离 Chromium 156.0.8078.4 中 5 项交互测试通过。覆盖 1440×1000 桌面、390×844 手机视口、浅色/深色、内置示例编译、追问→方案→失败修改→刷新恢复、密钥刷新清除、截图请求内容和数量限制、非视觉模型禁用上传、过期标签页防覆盖、请求中断不自动重试。截图在 `.local/screenshots/`。所有模型响应均为合成数据，不是模型连接验收。该工具是隔离的测试浏览器，不使用用户的浏览器资料。
- 最终 `npm audit --omit=dev`：0 个已知生产依赖漏洞。静态产物未检出测试密钥标记，所有运行测试未传入真实密钥。
- 未测试：真实付费 API 请求、模型图片识别质量、第三方签名、iPhone 导入/运行、真实软键盘、锁屏、大陆手机网络、线上托管。iOS 版本未知。
