## 案例 A：快递取件

合成短信：

> 【测试数据，请勿取件】您的两个包裹已到幸福路驿站，取件码分别为 3-2-8016 和 4-1-9027，请及时取件。

预期两条提醒：`幸福路驿站 · 3-2-8016`、`幸福路驿站 · 4-1-9027`，位于“快递取件”列表。

- [ ] 由另一设备实际发送测试短信，“包含取件”的新短信触发，不手动复制正文。
- [ ] 只提取原文中的站点、取件码；两件包裹分别记录。
- [ ] 重复处理同一短信不产生重复提醒；检查已完成/未完成记录策略。
- [ ] 分别测试“【测试数据】您的包裹已到站，请取件”（无站点、无码）、AI 无效返回、断网、授权撤销：有清楚反馈，不创建错误提醒。
- [ ] 不声称“取件”关键词覆盖所有快递通知。

## 案例 B：每日记账

输入：`今天午饭 28 元，打车 16 元。`（合成测试数据）

- [ ] 按 iPhone 当地日期生成两行：28.00、餐饮、午饭；16.00、交通、打车。
- [ ] 预览含日期、金额、分类、备注，并能确认、重新输入或取消。
- [ ] 只有确认后写入 `iCloud Drive/Shortcuts/Expenses/expenses.csv`。
- [ ] 无文件时创建 `日期,金额,分类,备注` 表头；已有文件只追加，既有行完全保留。
- [ ] 备注覆盖中文、英文逗号、双引号、换行，以及 `=1+1`、`+SUM(1,2)`、`@SUM(1,2)` 等公式开头；在 Numbers/Excel 中作为文本显示。
- [ ] 取消、网络失败、无效金额/分类、不完整 AI 响应不写入文件。
- [ ] 先设置临近时间，在真实 iPhone 锁屏验证重复提醒及启动链接；成功后恢复每天 22:00。
- [ ] 不依赖锁屏自动弹出输入框；使用通知中的链接主动进入录入。
